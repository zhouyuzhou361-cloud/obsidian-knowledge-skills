# 来源与访问说明

## 先按用户偏好选择

daily.sources 决定要检索的来源，daily.topics 决定主题，daily.social_languages 决定社交搜索语言。默认的 Web、YouTube、X 和中英文只是可修改起点，不强制每名使用者登录这些平台。

Web 优先原始公告、研究论文和产品发布；社交来源保留具体原帖；视频来源保留具体视频。搜索词包含主题和目标时间范围。只有标题或摘要时不能编译其未读取正文的细节。

## 按宿主可用能力执行

有连接器/API/搜索工具则使用用户已授权环境；可调用已有合法采集工具，但技能不附带工具或凭据。来源不可达时说明缺口，不自动注册账户、配置代理、安装新工具或向用户索取完整 Cookie。

无独立联网但有用户提供的材料时，注明基于哪些文件或摘录和相应日期；可写来源可追溯的材料汇编，不声称完成全网检索或独立核验。只有 URL 却无法访问正文时，请求提供可读内容。

## 可选的既有采集环境

可以复用用户已经配置的 twscrape 或其他采集器，但不强依赖其中任意一种。调用前检查实际版本的文档与接口。凭据保留在本地私有配置或凭据管理器，不进入仓库、聊天输出和日报；不假设代理端口。
