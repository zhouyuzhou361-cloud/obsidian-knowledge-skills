# 日报模板

替换方括号占位，按用户选定来源与主题增删板块。语言、标题 emoji、双语和篇幅按 writing 配置，日报目录按 paths.daily_dir。没有公开 URL 的用户材料用文件/段落引用替代，示例占位不能作为证据。

```yaml
---
title: "AI 行业日报"
date: YYYY-MM-DD
created: YYYY-MM-DD
tags: ["AI", "日报"]
sources: []
---
```

> 覆盖与限制：[实际来源、未能访问的渠道和未独立核验事项]

## 今日重点

[已核实事件及其影响；区分事实、观点和判断]
