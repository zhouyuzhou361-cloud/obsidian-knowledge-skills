# 🎯 多源输入与使用示例

使用前让 AI 读取对应单文件技能或完整标准技能目录。以下指令不依赖某个模型品牌；工具可用时执行，工具不可用时提供材料并在聊天中交付。

## 1. 视频、音频和播客

准备视频链接、上传文件或字幕/转录。链接本身不保证 AI 能读取视频；字幕未覆盖的画面和图表应说明缺口。

```text
请使用“整理知识库”整理这份视频字幕。
我想学会里面的方法，输出中文深度笔记，保留案例、条件和真实时间戳。
不要双语标题，不用 emoji；没有时间戳的段落不要自行估算。
我会自己保存，请返回 Markdown 和建议文件名。
```

## 2. PDF

优先提供文件；如只能上传部分页面，明确页范围。扫描件需要所在应用具备 OCR，提取失败时提供清晰页图或可读文字。

```text
整理我上传的 PDF，用页码标注关键结论、数据与图表。
区分作者论证、证据和你的归纳，保留限制条件。
按我提供的目录分类；这次只处理第 1–15 页，不当作全文总结。
```

## 3. 文章和网页

提供具体文章链接；无法访问全文时粘贴正文，保留已知作者和发布日期。只有标题、简介和搜索摘要不能代替正文。

```text
整理这篇文章，提炼可复用框架与边界条件。
这是文章正文和原链接，输出格式沿用我提供的笔记示例。
没有原文依据的机制解释请明确标为推断或缺失。
```

## 4. 直播和流媒体

提供录播、指定时间段、转录或已捕获片段。持续直播按已获得内容处理，不默认后台监听。

```text
整理这场直播的 00:15–00:45，材料在我提供的转录中。
区分不同发言人的立场，记录讨论、证据和仍未解决的问题。
只整理这个范围，不声称已读完整场。
```

## 5. 批量归档

文件助手需要用户明确范围；聊天模式可分批上传并逐批保存。

```text
我已提供个人配置。整理我授权目录里的 PDF、文章和视频转录。
先列出素材和状态，按来源与已处理范围去重，保留原文件。
新分类请让我选择，只有归档成功的材料才记为完成。
```

Clippings 也可作为其中一个目录，已有 processed 标签可用于增量扫描；不要求所有输入都先转成剪藏笔记。

## 6. 更新总导航

```text
读取我的导航页面、分类目录清单和配置，使用“更新知识库总导航”。
保留我的描述、顺序和快速入口；新增分类先给候选。
我没有 Dataview，请使用现有普通 Markdown 格式。
```

只有聊天能力时附上当前导航正文和目录清单，AI 返回可应用的修改；它无法凭空知道电脑上的文件是否存在。

## 7. AI 行业日报

```text
使用“AI 行业日报”，时区 Asia/Shanghai，范围最近 1 天。
只关注开源模型和 AI 产品，只使用 Web 官方公告，最多 8 条。
每条附具体来源，事实、作者观点和你的判断分开。
请在聊天里返回；来源不足时少写几条并说明。
```

如果 AI 没有联网能力，提供近期公告或报道正文，并要求标明“基于提供材料，未独立联网核验”。
